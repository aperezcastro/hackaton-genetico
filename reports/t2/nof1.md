# How we would know whether it works in this child

Generated by `scripts/t2/nof1.py`. Public parameters only; no patient data. The endpoint is the **frequency of micronucleated reticulocytes (%MN-RET)** measured by flow cytometry on peripheral blood.

## Why this endpoint

| Property | Value for this disease |
|---|---|
| What it counts | micronuclei — chromosome fragments left outside the nucleus by a missegregation event, i.e. the direct product of the defect rather than a proxy for it |
| Time window | reticulocytes circulate 1–2 days, so this is a **recent error rate**, unlike a lymphocyte karyotype, which accumulates over years |
| Sample | 240 µL of whole blood; flow cytometry scores ≥ 20,000 CD71+ reticulocytes (PMID 32761646) |
| Human validation | Dertinger 2003 (PMID 14644356); flow platform PMID 21164195; rose within 3–5 days of starting chemo- or radiotherapy in 9 of 10 adults (PMID 17059891) |
| Paediatric reference | upper bound of the 90 % tolerance interval in paediatric controls = **0.42 %** (PMID 32761646) |
| Measured in MVA | **never** — rung 0, worth doing whether or not any drug is ever given |
| Direction of information | falls if a drug reduces missegregation; **rises if a drug adds it**, which is why it doubles as a safety monitor (rapamycin is aneugenic in human lymphocytes in vitro, PMID 9914383) |

## Model and decision rules

Alternating on/off blocks; 20,000 reticulocytes per sample; assumed MVA baseline 2.0 % (about 5× the paediatric ceiling — **an assumption, never measured**), so the expected count is about 400 micronucleated cells per sample and log(y/N) is close to normal. **The between-visit variability σ is not assumed known**: it is estimated from the same data, so the posterior for the log rate ratio is a Student t with n − 2 degrees of freedom (flat priors on the mean, the effect and log σ). True σ in the simulations = 0.35. Every cell uses the same random numbers (common random numbers, 4,000 simulated trials), and each figure carries its Monte Carlo standard error.

| Responder rule | False-positive rate (8 visits per condition) |
|---|---|
| reduction >= 25 %, 95 % certainty | 0.0 % (± 0.0) |
| any reduction, 95 % certainty | 4.3 % (± 0.3) |
| any reduction, 90 % certainty | 10.0 % (± 0.5) |

The conventional rule (any reduction with 95 % posterior certainty) is calibrated: its false-positive rate is the advertised 5 %. The strict rule buys an almost zero false-positive rate at a large cost in power, because its threshold sits close to the effects one can hope for.
