# Track 2 — Allele-aware drug repurposing for *BUB1B* MVA

**The report is [`reports/latex/track2.pdf`](latex/track2.pdf)** (LaTeX source: [`latex/track2.tex`](latex/track2.tex);
figures by `scripts/figuras/figuras_t2.py`; pipeline in `scripts/t2/`; build with `python scripts/compila_informes.py`).
Two-page pharmacogenomic safety note: [`t2/safety_card.pdf`](t2/safety_card.pdf). One-page rung-0 protocol:
[`t2/rung0_protocol.pdf`](t2/rung0_protocol.pdf). Pitch video: https://youtu.be/YzJo-CZt5Ok

**Main result: a decision rule, not a single drug.** Every therapeutic line is classified by what it does to a
chromosomally unstable cell: *correct* fewer missegregation events, *clear* the abnormal cells, or *tolerate* help
them cope. No axis wins on the evidence, and each corrective line is blocked by a different, nameable fact about
this child. Today intermittent dasatinib (*clear*) ranks first, narrowly ahead of the JAK inhibitor ruxolitinib. The
mechanism-matched NAD⁺ line (niacin) ranks eighth, held back by two measurable facts: the class of the missense
allele (one immunoblot) and remission status (rhabdomyosarcoma depends on NAMPT/NAD⁺). Establish either and it
rises to third; establish both and it ranks first. So the first recommendation is a measurement, not a prescription.

**Tiers:** 0 · safety note (antimitotic and DNA-damaging drugs to discuss and monitor, never to drop a curative
regimen; growth hormone; NAD⁺ supplements; HSP90 inhibitors) and **measurement** (BUBR1 immunoblot; %MN-RET in
blood, never measured in MVA, with its power calculation) · 1 · intermittent dasatinib, to be tested first in the
BubR1 allelic mouse · 2 · an NAD⁺ precursor (niacin), gated on the allele class *and* documented remission ·
3 · low-dose sirolimus for muscle loss, with %MN-RET as a safety readout (rapamycin was aneugenic in one in-vitro
study) · 4 · JAK inhibitors only if an interferon signature is measured in the child · proteostasis amplification
declined (raising HSF1 is an aneuploidy-tolerating event) · read-through closed on current evidence (UGA-A context
+ NMD). All proposals are hypotheses for the clinical team, not treatment advice.
