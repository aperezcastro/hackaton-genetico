# Track 2 evidence reviews — working notes (2 October 2026)

Working material behind the Track 2 report, kept for transparency. **It is not the deliverable**: the report is
`reports/latex/track2.pdf`. These notes are a snapshot of 2 October 2026; later reviews changed several
conclusions, and **wherever a note and the final report differ, the report is the current version**. Known
examples: H1 (NAD⁺) is no longer the top-ranked line; PMID 27922816 concerns central-nervous-system myelin and no
longer supports extra caution with vincristine; the trials NCT03921554 and NCT04517253 are later paediatric JAK
inhibitor studies, not part of Sanchez 2018 (whose protocol is NCT01724580).

Some notes are in Spanish, most in English.
